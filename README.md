# Liposome encapsulation efficiency workflow

This repository contains a Chinese workflow page for the liposome CF encapsulation/retention experiment.

## Files

- `index.html`: 图文搭配的脂质体封存率实验流程图，包含重要名词和动词的英文注解与颜色标注。
- `liposome/`: 图片文件夹。当前 HTML 预期图片路径为 `liposome/1.jpg` 到 `liposome/12.jpg`。

## Notes

The HTML file has been added through the GitHub connector. Local JPG images cannot be uploaded through this connector as binary files, so please upload the 12 experiment images into a `liposome` folder in this repository to make all figures display on GitHub/GitHub Pages.
